## How this record works

One row per requirement. Each row has the check, the failure condition, and the result. The Phase 1 exit section links bounded reported local evidence; a merge alone does not show that tests passed. Real-platform results are still open. A result is filled in only with a link to the evidence: a test run at an exact commit, a saved response, or a reviewer verdict. The current Playbook has three tabs: Charter, Roadmap, and How It Works. These records live with the code.

## Platform facts the behavior relies on

- **E1 Free request cap** Workers Free: 100,000 requests per day. Verified. Date checked: not recorded. developers.cloudflare.com/workers/platform/limits
- **E2 Free CPU cap** Workers Free: 10 ms CPU per HTTP request. Verified, same page. Date checked: not recorded. That waiting on network calls does not count is reported.
- **E3 Pages and headers** Verified by the author. Sample: HEAD request to https://soliskit.github.io/ on 7 October 2026. It returned server GitHub.com and access-control-allow-origin *, and no X-Frame-Options, Content-Security-Policy, or Strict-Transport-Security. One sample is not proof for every response, and no way to set headers on Pages was found. Also verified at https://developers.cloudflare.com/workers/static-assets/headers/ : the header file is not applied to responses generated by Worker code, and headers for those must be sent from the Worker's own response.
- **E4 Pages terms** Verified. Date checked: not recorded. "GitHub Pages sites shouldn't be used for sensitive transactions like sending passwords or credit card numbers." Also not for running a business, e-commerce site, or commercial software as a service. docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits
- **E5 Mail provider quota** Resend is the selected provider (S27). Verified by the author on 7 October 2026. https://resend.com/pricing : Free is 100 emails a day, 3,000 a month, with 30-day data retention. https://resend.com/docs/knowledge-base/account-quotas-and-limits : the quota counts sent and received emails, and each recipient counts separately. What the 30-day retention covers is not stated in the text read.
- **E6 iCloud automated sending** Dropped by S10. Kept as evidence. Apple terms explicitly restrict automated access in the interference clause (item 10, https://www.apple.com/legal/internet-services/icloud/: accessing the Service through any automated means, like scripts or web crawlers); application to this code-mail service was unresolved. iCloud Mail is designed primarily for personal use, 1,000 messages a day (https://support.apple.com/en-us/102198).
- **E13 Gmail sending (superseded path)** Historical research for S10, which S27 replaces with Resend from mail.soliskit.com. Gmail is no longer the selected sender or an active later-phase gate. Verified by the author on 7 October 2026, partly. Personal Gmail: Google may block sending after more than 500 emails a day or more than 500 recipients in one email, and then the sender waits 1 to 24 hours; this is not guaranteed available quota (https://support.google.com/mail/answer/22839). Workspace limits are different (https://support.google.com/a/answer/166852) and do not apply to a free Gmail account. App passwords are not recommended, need 2-Step Verification, and Google prefers Sign in with Google (https://support.google.com/accounts/answer/185833). Google Terms of Service restrict automated access that breaks a site machine-readable instructions (https://policies.google.com/terms). Not yet researched: whether automated SMTP or API sending from a free Gmail account is allowed for this use, which credential type fits, and what Google does to an account used only to send sign-in codes. These questions remain unproven historical research, not checks required for the selected Resend path.
- **E7 Actions cost** Free for public repos on standard runners. Verified. Date checked: not recorded. docs.github.com/en/billing/concepts/product-billing/github-actions
- **E8 Other free-tier terms** Cloudflare storage limits, bot-challenge terms, plan terms beyond E1 and E2, and trusted source-address header behavior are unproven.
- **E10 Durable Objects on Free** Verified by the author on 7 October 2026. https://developers.cloudflare.com/durable-objects/platform/pricing/ : available on Workers Free with the SQLite backend only; free limits 100,000 requests per day, 5 million rows read per day, 100,000 rows written per day, 5 GB stored; past any free limit, further operations of that type fail with an error. Duration 13,000 GB-s per day. Point-in-time recovery covers the past 30 days (https://developers.cloudflare.com/durable-objects/api/sqlite-storage-api/). An alarm invocation is a compute request, and each setAlarm is a row written. https://developers.cloudflare.com/durable-objects/platform/limits/ : 5 GB per account on Free. https://developers.cloudflare.com/durable-objects/best-practices/access-durable-objects-storage/ : each object has private, transactional, strongly consistent storage.
- **E11 Worker crypto** Verified by the author. Date checked: not recorded. https://developers.cloudflare.com/workers/runtime-apis/web-crypto/ : Ed25519, HMAC, secure random values, and a timing-safe comparison are available in Workers.
